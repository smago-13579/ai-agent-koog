# ai-agent-koog

## Setup

### 1. I setup ollama CLI. Here's the [link](https://docs.ollama.com/quickstart)
### 2. Setup and run the llama model

~~2.1 Setup the llama model 3.1:8b model:~~ 
```bash
ollama pull llama3.1
```

2.2 Koog doesn't support model llama3.1. Install llama 3.2:3b instead:
```bash
ollama pull llama3.2:3b
```

2.3 Run the model:
```bash
ollama run llama3.2:3b
```
